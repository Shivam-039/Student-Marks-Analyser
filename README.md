# Student Marks Analyser

A simple and user-friendly web application that helps students calculate and analyse their academic performance.

The Student Marks Analyser allows users to enter the number of subjects, subject names, and marks. It then calculates the total marks, average marks, grade, and pass/fail result. It also provides subject-wise performance analysis and a visual performance distribution.

## Features

- Enter the number of subjects
- Add subject names dynamically
- Enter marks for each subject
- Calculate total marks
- Calculate average marks
- Automatically generate grades
- Display Pass/Fail result
- Subject-wise performance analysis
- Highest and lowest marks
- Overall average marks
- Performance distribution chart
- Overall performance analysis
- Responsive and clean user interface
- Smooth navigation between sections
