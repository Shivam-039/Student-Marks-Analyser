# 📊 Student Marks Analyser

A clean, browser-based web app that lets you enter a student's subject-wise marks and instantly get a full performance breakdown — total marks, percentage, grade, pass/fail status, and personalized insights on strengths and areas to improve.

**🔗 Live Demo:** [shivam-039.github.io/Student-Marks-Analyser](https://shivam-039.github.io/Student-Marks-Analyser/)

---

## ✨ Features

- **Guided input flow** — enter student details, subjects, and marks step by step instead of one long form
- **Student profile in results** — name, class, roll number, and exam name shown alongside the analysis (not just raw numbers)
- **Overall performance summary** — total marks, average/percentage, grade, and pass/fail status at a glance
- **Subject-wise breakdown** — a table with marks, percentage, and status (Excellent / Good / Needs Improvement / Poor) for each subject, with visual progress bars
- **Smart insights** — automatically highlights the strongest and weakest subjects with a short improvement recommendation
- **Responsive design** — works cleanly on both desktop and mobile, with a proper mobile navigation menu
- **Accessible & polished UI** — keyboard focus states, reduced-motion support, and consistent styling throughout

---

## 🛠️ Tech Stack

- **HTML5** — structure and markup
- **CSS3** — styling, layout, and responsive design
- **JavaScript (Vanilla)** — form logic, calculations, and dynamic result rendering
- **GitHub Pages** — hosting/deployment

No frameworks, no build step — just open `index.html` in a browser or visit the live link.

## 📖 How It Works

1. **Enter student details** — name, class, roll number, and exam name
2. **Add subjects and marks** — specify how many subjects and enter marks for each
3. **Get instant analysis** — the app calculates totals, percentage, and grade
4. **Review the breakdown** — see subject-wise performance with progress bars, plus your strongest subject and where to focus improvement
