ABOUT THE PROJECT

Student Marks Analyser

A simple student performance analysis system designed to make marks calculation and result analysis easier.

✦

What is this project?

Student Marks Analyser is a project that calculates student marks and provides a clear performance summary.

Users can enter different subjects and their marks to calculate the total, average, grade and pass or fail result.

✓

What does it do?

01

Calculates total and average marks.

02

Automatically determines the grade.

03

Shows pass or fail status.

04

Provides subject-wise performance analysis.

Designed to make student performance analysis simple, clear and easy to understand.
